# Luogu C Solutions

洛谷（[luogu.com.cn](https://www.luogu.com.cn/)）题目的个人 C 语言解答，按洛谷官方难度分类整理。

## 目录结构

```text
.
├── 01-入门/
├── 02-普及-/
├── 03-普及提高-/
├── 04-普及+/
├── 05-提高省选-/
├── CMakeLists.txt
└── README.md
```

每个 `.c` 文件对应一道题目，文件名通常使用洛谷题号，例如 `P1024.c`。每个源文件都包含自己的 `main` 函数，可以独立编译运行。

## 编译与运行

### 使用 GCC 或 Clang

```bash
gcc -std=c11 -Wall -Wextra P1024.c -o P1024
./P1024
```

### 使用 CMake

在项目根目录执行：

```bash
cmake -S . -B build
cmake --build build
```

CMake 会将各个题目分别配置为独立的可执行目标。新增题目时，把 `.c` 文件放入对应难度目录即可。

## 当前内容

仓库目前主要收录以下分类：

- 入门
- 普及-
- 普及提高-
- 普及+
- 提高省选-

题解以个人学习记录为主，代码不保证覆盖所有边界情况。建议结合题目原文、样例和自己的测试进行理解。

## 开发环境

- C11
- GCC 或 Clang
- CMake 3.20 或更高版本（可选）
